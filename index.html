Can you explain how async/await works in JavaScript with a quick example?
✦
AuraAI 2:15 PM
Great question! async/await is syntactic sugar built on top of Promises that makes asynchronous code read like synchronous code.

You mark a function with async, and inside it you can use await to pause execution until a Promise resolves — without blocking the main thread.

Here's a quick example:

async function getUser() {
  const res = await fetch('/api/user');
  const data = await res.json();
  return data;
}

If an error occurs, you can wrap it in try/catch just like synchronous code. Clean and readable! 🚀
